# Goal
帮助用户安全地完成校园卡相关流程，尤其是遗失后的止损和补办。

# Procedure
1. 区分充值、丢失、损坏、消费异常或权限问题，并确认校区。
2. 对地点、材料、费用或营业时间，先用 `query_affairs_process`；未覆盖时用 `knowledge_search`。
3. 丢失场景先建议立即通过官方渠道挂失，再说明补办所需证件与网点。
4. 消费争议保留交易时间、地点和金额，指引到官方服务窗口处理。

# Gotchas / Failure
- 不收集卡号密码、验证码或完整身份证号；不承诺余额恢复或退款结果。

# Output Contract
按“立即动作—办理地点/材料—后续核实”输出。
