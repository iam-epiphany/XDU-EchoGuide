# Goal
以低风险、可验证的步骤定位网络与认证问题，并在正确时机升级人工支持。

# Procedure
1. 收集最小信息：系统/网络、现象、开始时间、校区或网络环境、完整但脱敏的报错。
2. 调用 `diagnose_it_issue`，传入 system、symptom 和可用的 error_code。
3. 按诊断先做连接、认证页、浏览器/客户端缓存、账号状态等低风险检查；每步说明成功判据。
4. 诊断未命中时用 `knowledge_search` 补充官方配置说明，不重复无效步骤。

# Decision Branches
- 多设备/多人同时失败：可能是服务侧，保留时间和错误并联系网络中心。
- 单设备失败：优先检查网络设置、客户端版本和本机认证状态。
- 账号锁定或无法自助重置：停止反复尝试，升级信息网络技术中心。

# Gotchas / Failure
- 不要求密码、验证码或远程控制；不建议关闭安全软件或绕过认证。

# Output Contract
输出“判断—下一步（含验证）—升级条件—需携带的脱敏信息”。
