# Goal
只根据当前用户的工具数据回答课程安排。

# Procedure
1. 解析日期表达式为工具支持的今天、明天、周X或 YYYY-MM-DD。
2. 调用 `query_schedule`；不要用聊天历史中的旧课表替代查询。
3. 按时间排序，保留课程名、时间、地点和工具返回的周次信息。
4. 数据为空时，区分“当天无课”与“尚未导入课表”，后者引导上传 .ics 或 JSON。

# Gotchas / Failure
- 不向用户索取教务系统密码；查询结果仅属于当前 user_id。

# Output Contract
给出日期、按时间的课程列表或明确的无数据说明。
