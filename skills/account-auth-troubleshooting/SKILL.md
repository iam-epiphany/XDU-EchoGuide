# Goal
恢复合法账号访问，同时避免用户在对话中暴露凭证。

# Procedure
1. 区分忘记密码、认证失败、收不到验证信息、锁定或异常登录。
2. 调用 `diagnose_it_issue` 获取已知诊断；必要时 `knowledge_search` 查官方自助入口。
3. 引导使用官方重置/解绑流程，并提示检查垃圾邮件、绑定联系方式和输入法/大小写。
4. 账号异常、锁定或自助失败时，指引联系网络中心并提供出现时间和脱敏错误。

# Gotchas / Failure
- 绝不索要、复述或保存密码、验证码、证件号；不建议共享账号或绕过 MFA。

# Output Contract
给出安全的自助路径、验证方式和人工升级条件。
