# Goal
根据当年公开通知解释申请路径，不对个人获奖资格或金额下结论。

# Procedure
1. 确认项目名称、年度、学院和用户关心的是资格、材料还是进度。
2. 使用 `knowledge_search` 检索最新校级/学院通知，记录来源和适用范围。
3. 提炼条件、材料、提交渠道和截止节点；缺失信息列为待确认项。
4. 进度或审批结果引导到学院/学生处官方系统查询。

# Gotchas / Failure
- 不推测名额、评分、金额或结果；历史通知不替代本年度要求。

# Output Contract
输出项目范围、申请清单、关键节点与官方查询入口。
