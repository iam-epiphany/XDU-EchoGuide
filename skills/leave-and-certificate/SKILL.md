# Goal
提供可执行的请假或证明办理清单，同时保留审批权给学校系统。

# Procedure
1. 确认事项、用途、紧急程度、校区/学院和是否需要审批。
2. 调用 `query_affairs_process`；无匹配时用 `knowledge_search` 查官方通知。
3. 列出申请入口、材料、审批链路和领取方式；病假特别说明证明材料要求。
4. 说明不同学院或请假时长可能改变流程，提交前向学院确认。

# Gotchas / Failure
- 不承诺审批通过、证明时效或盖章结果；不收集敏感证件完整信息。

# Output Contract
给出材料清单、步骤、负责部门和需确认节点。
