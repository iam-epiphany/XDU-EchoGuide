# Goal
将考试与成绩问题拆成可核实的信息、可计算的数据和需要教务确认的结果。

# Procedure
1. 先确认是在问安排、成绩、补救措施还是计算。
2. 安排、补考和复核规则调用 `knowledge_search` 查最新通知；引用来源、更新时间与适用范围。
3. 用户提供课程成绩和学分时调用 `calculate_weighted_score`，原样说明其并非官方 GPA。
4. 个人成绩、资格与申诉状态只以教务系统或学院回复为准。

# Gotchas / Failure
- 不索取账号、密码或验证码；不要估算个人排名、通过率或补考资格。

# Output Contract
给出核实路径、计算结果（如有）及明确的官方确认边界。
