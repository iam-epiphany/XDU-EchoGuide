# Goal
把政策文本转成适用条件与行动清单，而不是替学生作资格结论。

# Procedure
1. 确认事项、入学年份、学院和拟适用年度。
2. 用 `knowledge_search` 找到官方通知；标注校级/学院级、发布日期和适用对象。
3. 分离硬性条件、待补材料和时间节点；对冲突或缺失信息说明不确定性。
4. 提供学院教务或主管部门的核实路径。

# Gotchas / Failure
- 名额、排名线和最终资格不能推断；旧通知仅作历史参考。

# Output Contract
输出“适用范围—条件—材料/节点—待确认问题”。
