# 归档目录说明

本目录存放 EchoGuide（西电校园智慧助手）**历史废弃方向**的产物，仅供追溯参考，**不参与当前校园场景的构建与部署**。

| 路径 | 内容 | 废弃原因 |
|------|------|----------|
| `SuitGuard-金融科技大赛项目实施计划.md` | 将通用客服底座改造成"银行理财适当性审查"的金融科技大赛计划（v1.1） | 方向已变更为西电校园助手，金融术语会误导场景 |
| `agentrange/` | AgentRange 安全靶场赛题的 Compose overlay 集成 | 靶场环境与校园业务无关，已从 `integrations/` 移出 |

注意：归档文件中的环境变量、API Key、路径均可能过时，**不要直接照搬**。当前项目配置以根目录 `.env.example` 为准。
