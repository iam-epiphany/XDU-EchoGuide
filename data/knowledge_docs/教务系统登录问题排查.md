# 教务系统登录问题排查

教务系统（jwxt）与一网通办（ehall.xidian.edu.cn）、校园邮箱共用学校统一身份认证账号体系，账号为学号（教职工为工号）。

登录提示"密码错误"时的排查步骤：
1. 确认账号正确：输入学号/工号，不要带空格；注意大小写锁定与全角/半角状态。
2. 验证账号状态：尝试登录一网通办等其他校内系统，判断是账号问题还是教务系统本身问题；其他系统能登录而教务系统不能，多为教务系统侧故障或高峰拥堵。
3. 密码重置：统一身份认证提供自助重置密码服务，通过绑定的手机号或邮箱验证后重置；重置后等待约 10 分钟同步，再重试登录教务系统。
4. 清理缓存：换无痕窗口或更换浏览器重试，排除 Cookie/缓存干扰。
5. 网络环境：校外访问需先连接 VPN（WebVPN），校内访问不受影响。

若上述步骤仍无法解决，可联系学校信息化处（统一身份认证）或教务处（教务系统），办公时间以部门公告为准。
