# 校园卡异常处理

校园卡使用中可能出现以下异常情况：

1. 卡片损坏：卡片折断、芯片损坏导致无法刷卡时，需本人携带身份证件到校园卡服务中心申请换卡，按学校规定收取工本费，原卡余额可结转至新卡。
2. 卡片冻结：校园卡因挂失、系统检测到异常交易等原因被冻结时，刷卡会提示"卡被冻结"。本人携带身份证件到校园卡服务中心办理解冻；因挂失冻结的，解冻前需先取消挂失。
3. 刷卡无反应：可能是卡片消磁或读写问题，可先尝试在圈存机重新写卡；仍无效则到服务中心检测换卡。
4. 余额异常：消费扣款与余额不符时，保留消费凭证，到校园卡服务中心核对交易流水处理。

异常处理请优先联系校园卡服务中心，不要自行拆解卡片。
