# 请假流程说明

西电学生请假统一通过学校一网通办平台（ehall.xidian.edu.cn）线上办理，具体流程如下：

1. 准备材料：请假事由、起止时间；病假需提供病历或诊断证明，事假需提供相关说明材料。
2. 线上提交：登录一网通办，进入"请假申请"服务，填写事由、起止时间并上传证明材料后提交。
3. 审批流转：短期请假（一般为 3 天以内）由辅导员/班主任审批；较长请假按层级逐级上报至学院、学校审批；具体时限以学院规定为准。
4. 销假：假期结束后返校，按学院要求在系统内办理销假手续。

紧急情况：突发急病等无法提前线上申请时，先联系辅导员说明情况，事后及时补齐线上流程。

请假期间涉及课程考核安排的，需提前与任课教师沟通；涉及缓考的按缓考规定另行申请。
