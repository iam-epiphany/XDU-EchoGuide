# 校园网连接问题排查

宿舍校园网（含无线网）认证成功但无法上网时，问题通常在网络通路或 DNS 层面，按以下顺序排查：

1. 重连验证：断开网线/Wi-Fi 后重新连接并重新认证，确认认证状态真实生效。
2. 区分 DNS 与网关问题：浏览器尝试访问一个 IP 直连地址（如校内 IP 或 202.100.64.68 等公网 IP），再访问一个域名（如 baidu.com）：
   - IP 能打开、域名打不开 → 多为 DNS 解析问题，可尝试修改 DNS 为 223.5.5.5（阿里）或 114.114.114.114（114DNS）后重试；
   - IP 和域名都打不开 → 多为网关/路由层面问题，检查网关地址与 IP 获取是否正常。
3. 重启终端与接入设备：重启电脑、路由器/交换机，重新获取 IP。
4. 多设备对比：用手机连接同一网络测试，判断是单设备问题还是网络整体问题。
5. 联系报修：仍无法解决时通过后勤报修系统提交网络报修，或联系信息化处，办公时间以部门公告为准。

上网认证账号与统一身份认证账号一致，认证成功但无法访问时不要反复修改密码。
