# 在读证明办理说明

在读证明（学籍证明）用于留学申请、求职、银行/公积金业务等场景，办理方式如下：

1. 线上自助办理：登录学校一网通办平台（ehall.xidian.edu.cn），搜索"在读证明"或"学籍证明"服务，选择用途与语言后在线生成，可直接下载或自助打印。
2. 自助打印终端：校内设有自助打印终端，凭校园统一身份认证账号登录后可打印带章的学籍证明/在读证明。
3. 盖章原件：需要盖章原件的，按自助打印页面指引前往对应部门办理——本科生到本科生院，研究生到研究生院；办理需携带本人学生证或身份证。

线上办理无需提交纸质材料，仅需校园统一身份认证账号；电子证明与纸质证明具有同等效力（以用途接收方要求为准）。办理中遇到问题可咨询所在学院教学办或学生一站式服务中心。
